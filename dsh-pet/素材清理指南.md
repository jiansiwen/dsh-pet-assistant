## 三、脚本整理（130 个 → 建议留 12 个）

**⚠️ 先说清楚：脚本总共才几百 KB，删了不省空间。整理是为了"下次一眼能找到"。**

### 建议保留（核心工具链）

| 脚本 | 作用 |
|---|---|
| `ingest-action-v2.py` | 视频 → 序列帧（三种锚定模式）|
| `split-segments.py` | **长视频裁多段 + 循环点搜索 + 全局对齐**（最常用）|
| `make-strip.py` | 通用帧条带（目视核对）|
| `strip-upper.py` | **任意纵向区间放大**（找局部动作必用）|
| `install-prepared.py` | 装机（含 Windows 文件锁重试）|
| `pose_metrics.py` | 姿态指标的唯一实现 |
| `verify-eyes.py` | 睁/闭眼核验 |
| `compare-grab.py` | 原版 vs 新版量化对比 |
| `cmp-sleep.py` | 两版素材多指标对比 |
| `sleep-seg.py` | 分段测量（防过渡段污染）|
| `split-laptop.py` | laptop 专用裁段 |
| `inventory.py` | 本次清点工具（可留，以后还能用）|

### 其余约 118 个可删

主要是这几类（都是"当时查一个问题"的一次性脚本）：
- `build-*.py`（19 个）— 生成各种演示页/对比页
- `check-*.py`（18 个）— 各种检查
- `ex-*.py` / `extract-*.py` / `strips-*.py`（10 个）— 抽帧
- `measure-*.py` / `diag-*.py` / `verify-*.py` / `recheck-*.py`（20 个）— 测量诊断
- `loop-*.py` / `find-*.py` / `fix-*.py` 等（其余）— 试错过程

**这些脚本里确实有几个是"唯一实现"**（比如 `fix-pose-ground.py`、`recenter-action.py`），
但对应的功能**已经并进 `split-segments.py` 的 `anchor` 参数**了，所以不再是唯一依赖。
